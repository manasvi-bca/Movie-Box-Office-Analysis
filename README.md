# Movie Box Office Analysis

## Project Overview
This project analyzes movie box office data using Microsoft Excel. An interactive dashboard was created to understand movie performance, revenue, genres, ratings, and runtime.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis

## Dashboard Features
- Total Gross Revenue
- Average Gross Revenue
- Maximum Movie Score
- Total Movies
- Genre-wise Analysis
- Average Runtime by Movie Genre
- Top 10 Genres by Average Gross Revenue
- Interactive Slicers

## Key Skills Demonstrated
- Data Cleaning
- Data Analysis
- Excel Dashboard Creation
- Pivot Table & Pivot Chart Analysis
- Data Visualization
- Interactive Reporting
